# COPYWRITING & VOICE GUIDELINES
## Establishing Human-First, Jargon-Free Clarity Across All Touchpoints

This guide defines the copywriting principles and voice guidelines for the MarketForge platform. We communicate using clear, humble, plain English. We explain concepts as we would to a ten-year-old, ensuring first-time business owners can confidently navigate the application without technical assistance.

---

## 1. Core Principles

### A. Simple Over Smart
Never try to sound clever or "tech-forward" at the expense of clarity. Use the shortest, most common word that accurately conveys meaning.
* **Bad**: *"Our autonomous background orchestration cycle has successfully completed optimization sequences."*
* **Good**: *"Your updates have been saved successfully."*

### B. Active, Direct Voice
Use clear, action-oriented verbs. Tell the user exactly what to do or what occurred.
* **Bad**: *"An unexpected exception event was thrown during database transaction persistence."*
* **Good**: *"We couldn't save this change. Please check your internet connection and try again."*

### C. The 5-Second Test
Every heading, button, tooltip, and empty state must be scannable in under 5 seconds. If a user has to read a sentence twice to understand it, the copywriting has failed.

---

## 2. Forbidden Vocabulary & Simple Replacements

To maintain a consistent, trust-worthy atmosphere, we have banned complex technical jargon from the interface. Use these direct translations:

| ❌ Forbidden Term (Complex & Technical) | ✅ Mandatory Replacement (Simple & Friendly) |
| :--- | :--- |
| **Tenant / Realm / Instance** | Business / Organization / Workspace |
| **Provisioning / Deploying** | Setting up your Business |
| **Workspace Environment** | Business Workspace |
| **Telemetry / Diagnostics** | System Reports / Usage |
| **RBAC / Policy Mapping** | Roles & Permissions |
| **Lifecycle State / Active Stage** | Status / Progress / Active Steps |
| **Automation Rules Engine / Cron** | Automations / Smart Actions |
| **Knowledge Assets** | Documents & Templates |
| **AI Core / Cognitive Model** | Smart Assistant |
| **API Webhook Gateway** | System Connection |
| **Subscription Entitlement Plan** | Subscription Plan |
| **Module** | Feature / Tool |

## 3. Copywriting Examples (Before vs. After)

### A. Headings & Subheadings
* **Before**: `Module 10 Actionable Executive Home: Multi-tenant SaaS Health Monitor`
* **After**: `Good morning! Here is how your business is performing today.`

### B. Primary Buttons
* **Before**: `Initiate Provisioning Sequence`
* **After**: `Set Up My Business`
* **Before**: `Commit Action Node`
* **After**: `Save Changes`

### C. Tooltips
* **Before**: `Hover to inspect active client metadata and transaction payloads mapped to firebase-blueprint indices.`
* **After**: `View contact history, booking amounts, and guest preferences.`

### D. Dialogs & Modals
* **Before**:
  > **Header**: `Confirm Tenant De-provisioning`  
  > **Body**: `This operation will permanently destroy the active workspace slices, databases, and assets. This state change is irreversible.`
* **After**:
  > **Header**: `Are you sure you want to delete this business?`  
  > **Body**: `This will permanently delete all records, bookings, and team members. You won't be able to undo this action.`

### E. Notifications
* **Before**: `[SUCCESS] Client database node state synchronized in 45ms. Auth domains updated.`
* **After**: `Success! Guest information was updated successfully.`

### F. Empty States
* **Before**: `Warning: Current query yielded 0 collection items inside goals-strategy-os index.`
* **After**: `No bookings found. Try adjusting your dates or add a new booking to get started.`
